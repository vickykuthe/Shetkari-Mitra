# 🌾 Shetkari Mitra – Farmer Government Aided Schemes Platform
# Vicky Kuthe (web developer)
## 📌 Overview
**Shetkari Mitra** is a web-based application designed to empower farmers by providing easy access to government-aided agricultural schemes, crop recommendations, and pesticide/insecticide information. The platform allows farmers to apply for schemes, view their application status, and stay informed about best practices for cultivation — all through a simple and mobile-friendly interface.

## 🎯 Objective
To build a centralized digital platform that simplifies access to agricultural e-services and schemes for farmers, ensuring transparency, convenience, and region-specific guidance for crop planning and protection.

## ⚙️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend & Realtime Database:** Firebase
- **Authentication:** Firebase Auth
- **Hosting:** Firebase Hosting or cloud/local deployment

## 🧩 System Modules

### 🔐 Admin
- Login
- Post government schemes
- Post crop details
- Approve or reject farmer applications

### 👨‍🌾 User (Farmer)
- Register / Login
- View government schemes
- View seasonal crop and pesticide information
- Apply for schemes
- Check application status

## 🔄 Key Features
- Farmer-friendly UI/UX
- Real-time scheme application and approval tracking
- Seasonal crop suggestions based on region
- Secure authentication and cloud data storage
- Mobile-responsive design
- Logging of actions for transparency
